How violations are flagged
  1. After every conversation, an AI Investigator reads every question, answer and message, and reports anything an agent learned or changed that it must never.
  2. Code confirms each finding against the real data: is it true, and can it really be worked out from answers that agent received? Unconfirmed claims are rejected.
  3. Simple code checks run as a backstop, and show anything the Investigator missed.
